# Audio review reference samples

These short Spanish, French and German samples were generated locally with macOS speech synthesis from original demonstration scripts. They are interaction fixtures, not ElevenLabs output, translations of the simulated source videos, or provider quality benchmarks. The application labels them as reference previews and also accepts user-selected local audio files. No real customer audio is bundled.

The matching MP4 files are waveform visualizations of these same local reference recordings. They contain no talking face and are not Sync results or assembled source programs. The final-review UI labels them as interaction fixtures. All MP3 and MP4 files were duration-checked with ffprobe.
